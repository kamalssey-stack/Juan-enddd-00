👟 Juan Shoes Store

## 🇬🇧 English

Juan is a shoe-store web application built with ASP.NET Core MVC, Razor Views, Entity Framework Core, SQL Server LocalDB, and ASP.NET Core Identity.

### ✨ Features

- 🏠 Storefront with a database-driven homepage slider, product collections, product details, search, category filtering, sorting, and pagination.
- 🏷️ Product discounts displayed as a sale price and the original price.
- 🛒 Shopping basket for guests (browser cookie) and signed-in users (database).
- 📦 Checkout with stock validation, order creation, and cash on delivery. No online card-payment provider is configured.
- 🔐 Customer accounts, email confirmation, resend confirmation, password reset, optional Google sign-in, and authenticator-based two-factor authentication.
- 👤 My Account page with customer details and order history.
- 📧 Newsletter subscriptions and email notifications when new products are added.
- 📝 Blog articles stored in the database, shown on the storefront, and managed in the admin area.
- 🧰 Admin area for products, categories, homepage sliders, blog posts, orders, and dashboard statistics.
- 🖼️ Uploaded product, slider, and blog images are stored under `wwwroot/assets/img`.

### 🧩 Requirements

- .NET 8 SDK
- SQL Server LocalDB (or another SQL Server connection string)
- Visual Studio 2022 or the .NET CLI
